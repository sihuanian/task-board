# 需求文档：卡片列头隐藏/显示图标更换为小眼睛图标

- WorkItem：wi-t1000001
- 变更序号：requirements（revision 0）
- 文档基线状态：首次需求分析（迭代任务，基于当前代码基线）
- 目标设备：桌面 Web（浏览器）

## 1. 项目背景与目标

当前产品是一个纯前端的任务看板单页应用（`app/`），三列看板（待办 / 进行中 / 已完成），每列头部右侧提供一个"隐藏/显示列"按钮。

现状事实（读取自当前代码基线）：

- 该按钮内容为三个点（`•••`），定义于 `app/app.js:96`：`title="隐藏/显示列"`、`aria-label="切换{列}列可见性"`。
- 点击后调用 `store.toggleColumnVisibility(col)` 并重绘，被隐藏的列整体加上 `.column.hidden` 样式，即 `display: none`（`app/style.css:355`）。
- 由于整列（含列头按钮本身）消失，列隐藏后无法从该列恢复；顶栏另有"显示所有列"按钮（`app/index.html:35`，逻辑见 `app/app.js:596`）用于恢复。

用户目标：把"隐藏/显示列"按钮的图标从三点符号替换为**小眼睛图标**，视觉隐喻参照密码输入框右侧的眼睛图标（用于切换可见性）。

成功结果：看板每列头部的隐藏/显示按钮以小眼睛图形呈现，替换原有的三点符号，且列隐藏/显示功能与可访问性行为保持可用。

## 2. 用户旅程与关键场景

场景 S1 —— 切换列可见性：

1. 用户打开任务看板；
2. 用户在某列头部看到一个小眼睛图标按钮；
3. 用户点击该眼睛按钮；
4. 系统隐藏该列，看板只显示其余列；
5. 用户点击顶栏"显示所有列"按钮，系统恢复全部列，被恢复列头部重新显示眼睛按钮。

关键决策点：用户通过"眼睛"这一通用可见性隐喻识别该按钮的用途，无需依赖文字提示。

## 3. 状态模型与业务规则

- 每列存在两种可见性状态：可见、隐藏（沿用现有模型，`state.columnVisibility[colKey]`）。
- 状态转换：可见 ——(点击眼睛按钮)→ 隐藏；隐藏 ——(点击"显示所有列")→ 可见。
- 通用约束（本次不改变）：可见列的列头渲染眼睛按钮；被隐藏的列整体不渲染（`display: none`），因此该列的眼睛按钮不可见也不可点击，恢复入口为顶栏"显示所有列"按钮。

## 4. 分模块功能需求

### 4.1 列头隐藏/显示按钮图标

- 按钮改为使用**眼睛图形**（SVG）呈现，替代原有三点符号 `•••`。
- 眼睛图标表达"可见性切换"语义，参照密码输入框中眼睛图标的常见形态（睁眼 / 闭眼含斜杠两种造型）。
- 按钮的点击行为、所在位置（列头部右侧）与所属功能（切换该列可见性）保持不变，仅更换其呈现的图标图形。
- 按钮保留 `title` 与 `aria-label`，用于悬停提示与无障碍朗读（详见第 5 节）。

推荐基线（可安全推导，标注为推荐基线而非用户已确认的产品决定）：

- R1 图标状态：当列可见时，按钮显示"睁眼"图标，表示当前列可见；若列被隐藏，图标语义对应"闭眼/眼睛带斜杠"。由于隐藏列当前整体不渲染（现有行为，本次不改变），实际可见场景中该按钮呈现"睁眼"图标。
- R2 图标规格：采用内联 SVG、`stroke="currentColor"`、`stroke-width="2"` 的描边风格，与页面其它图标（见 `app/index.html` 中导出、深色模式等按钮）保持一致，尺寸与列头部协调（约 14–16px）。
- R3 交互反馈：按钮 hover 时沿用现有可点击反馈（颜色变化 + 浅色背景，见 `app/style.css:339-352`）。

### 4.2 边界与异常

- 当某一列被隐藏后再通过"显示所有列"恢复时，该列头部的眼睛图标应正常重新渲染，无残留的三点图标。
- 在深色与浅色两种主题下，眼睛图标均清晰可见（颜色继承当前主题文本色）。
- 页面首次加载时，所有列默认可见，眼睛图标正常显示。

## 5. 非功能要求

- 视觉一致性：眼睛图标的线宽、风格与页面既有 SVG 图标保持一致，不引入风格冲突的位图或彩色图标。
- 可访问性：按钮保留可读的 `title` 提示文本（如"隐藏/显示列"语义）与描述性 `aria-label`（说明其作用列与可见性切换），按钮可通过键盘聚焦。
- 主题适配：图标颜色使用主题变量（`currentColor`），在深色与浅色主题下均可辨识。
- 本次为纯前端呈现层变更，不涉及数据持久化结构变更；列可见性状态的持久化行为保持与现状一致。

## 6. 明确不在当前范围内的能力

- 不改变列隐藏的交互模型：不新增"隐藏后仍保留列头、以斜杠眼睛图标就地恢复"的持久单列恢复控件（现有恢复入口仍为顶栏"显示所有列"按钮）。
- 不更换页面中其它按钮或卡片的图标（导出、深色模式、删除等）。
- 不改动看板的列数量、列含义、拖拽、内联编辑、搜索、导出等既有功能。
